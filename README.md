NASA Image Explorer
A modern Angular 21 application for exploring NASA's Astronomy Picture of the Day (APOD) archive with Material Design.
Features

🏠 Home Component: View today's astronomy picture
🖼️ Gallery Component: Browse random astronomical images
🔍 Search Component: Find images by date or date range
⭐ Favorites Component: Save and manage your favorite images
📱 Image Detail Component: View detailed information about each image
💾 Local Storage: Persist favorites across sessions
🎨 Material Design: Beautiful, responsive UI

Technologies Used

Angular 21.0.0
Angular Material Design
NASA APOD API
RxJS
TypeScript
SCSS

Prerequisites

Node.js (v18 or higher)
npm or yarn
Angular CLI 21.0.0
